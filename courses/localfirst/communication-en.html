Communicating with the network

Connectivity alone does not grant authority to use the system.

Interface and identity

Define message format, sender identity, authentication, validation and response. Requests are denied unless explicitly permitted.

Separate permissions

Read, write, export and command execution are separate permissions. Scope each operation to its target and data.
